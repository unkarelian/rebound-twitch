Rebound for Twitch

An open-source ad blocker for Twitch that repairs itself quickly when Twitch changes something. Values that Twitch rotates (GraphQL query hashes, the web client ID, ad markers) come from a small signed data file. The extension checks its Ed25519 signature and rejects anything unsigned, altered, or malformed. That file holds data only, never code.

Privacy

No telemetry. The extension makes two requests of its own: it downloads the signed config, and it downloads a public status file that shows when blocking was last verified to work. Neither request includes anything about you. "Report broken" opens a GitHub issue form that you can read and edit before you send it.
